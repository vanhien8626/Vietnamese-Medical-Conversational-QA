# Vietnamese Medical Conversational QA

Đồ án minh họa hệ thống đọc hiểu và hỏi đáp nhiều lượt trên văn bản y tế tiếng Việt.

## Chức năng
- Nhập văn bản y tế tiếng Việt.
- Đặt câu hỏi dựa trên nội dung văn bản.
- Lưu lịch sử hội thoại để hỗ trợ câu hỏi tiếp theo.
- Tìm câu trả lời phù hợp trong văn bản.
- Báo khi văn bản không có đủ thông tin thay vì tự suy đoán.

## Công nghệ
- Python 3
- Flask
- HTML/CSS

## Cài đặt
```bash
pip install -r requirements.txt
python app.py
```
Sau đó mở trình duyệt tại `http://127.0.0.1:5000`.

## Lưu ý
Hệ thống được xây dựng cho mục đích học tập và minh họa đồ án, không thay thế tư vấn hoặc chẩn đoán của bác sĩ.
